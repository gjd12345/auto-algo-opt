# 里程碑三四臂 × 三独立随机种子同总预算 (B_total=36) 归因实验证据 (500ms & 25ms)

本卡片汇总里程碑三阶段 3C 的 **24 场全在线对照实验**（2 预算 × 4 实验臂 × 3 随机种子 `[20261124, 20261125, 20261126]`，同一模型 `deepseek-v4.1-flash`，`dev_24` 可见、`select_64` 与 `blind_120` 彻底物理隔离）。

## 定义或方法步骤

1. **`500 ms` 主对比 (`select_64` 三种子逐例与均值 ± 尝试/成功请求)**：
   - **Arm M3-0 (纯 EoH)**: `[20.7811, 23.2672, 21.6584]`，均值 **`21.9022`**（avg att `33.67` / ok `28.67`）。
   - **Arm M3-1 (纯文本反思, 对标 PyVRP+)**: `[22.9304, 20.7811, 22.3867]`，均值 **`22.0327`**（avg att `36.0` / ok `31.67`）。
   - **Arm M3-2 (完整研究代理 · 锁定 L2a)**: `[20.741, 20.7456, 20.7177]`，均值 **`20.7348`**（avg att `36.0` / ok `28.33`）。
   - **Arm M3-3 (完整研究代理 · 全动态 `{L1,L2a,L2b,L3}`)**: `[20.8103, 20.717, 20.738]`，均值 **`20.7551`**（最优 **`20.7170`**，avg att `36.0` / ok `29.67`）。
2. **`25 ms` 预算自适应对比 (`select_64`)**：
   - `M3-0 = 22.4032`、`M3-1 = 23.0255`、`M3-2 = 20.7517`（最优 **`20.6733`**）、`M3-3 = 20.8741`（`0/64` 超时，稳健保留静态 `L2a (none)`）。

## 适用条件、假设与限制

- 在未注入静态 KB 线索的公平设定下，纯 EoH 与纯文本反思极易出现多颗种子滞留于逐对局部归一化退化区间（`21.6–23.3`），而完整研究代理通过动态检索 KB 与五关校验，在两档预算的全部 `6/6` 粒自主代理种子上实现稳定复现。
