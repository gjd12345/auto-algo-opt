# 网络资料登记

本目录只登记宿主 Agent 检索和阅读过的公开来源。sources.json 是机器可校验的来源清单；本文件保留查询词、筛选理由和许可边界。首轮每个目标问题族筛读 3 个候选，未下载无权分发的全文，发布包只复制书目信息和自主摘要。

来源结论必须定位到作者/出版社记录中的摘要、页码或章节。论文的硬件、实例和跨套件分数不迁移到本仓库的历史成绩；历史代码与评测必须另外用 main 的 blob hash、suite、指标和预算绑定。

允许登记 URL；禁止执行下载脚本、加载任意 pickle、绕过认证、关闭 TLS 校验。若后续保存公开全文，文件必须进入受限原始资料区并记录 hash、许可和发布排除理由。
