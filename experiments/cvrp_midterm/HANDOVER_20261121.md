## 1 · 一句话现状

本轮中期研究包含两个已完成的阶段与完整离线复验（统一总报告见 [`REPORT_MIDTERM_SYNTHESIS.md`](REPORT_MIDTERM_SYNTHESIS.md)）：

1. **第一阶段（`a1–a5` 静态引导 + `b4` 自动模板双臂对照 + 方向二 96 实例 v4）**：
   - **方向二（96 实例 / `n=50`）**：`A/B/C` 入池后互补间隙 **4.09%**，单特征 `cluster_stump_loo` 取得 **+0.93% `[+0.07%, +1.81%]`**（`p_boot = 0.0163`）。
   - **方向一 `b4` 配对对照（`NN` 起点，各 4 轮 / 24 次已完成 EoH 请求）**：`b4_finding_only` 在共享 6 例开发诊断集取得 **`11.4718`**（相对配对 `b4_control` `11.8055` 缩短 **`2.83%`**，较 `Frozen C` `10.9197` 高 **`+5.06%`**）。经 P0/P1 离线复验：`b4_finding_only` 20 个生成候选中 **2 个被正式评测拒绝**（R2 `count_nonzero`、R3 `ix_`），余 18 个正式有效且无 `spread >= 5%`、无跨轮精确代码重复；**第 2–4 轮 `decision_summary` 去除数字后为同一建议模板**。
2. **第二阶段（`S2` 外部 Coding Agent 数学分析 + `P0-120` 盲测 + `hetero-288` 闭环选择，见 [`REPORT_STAGE2.md`](REPORT_STAGE2.md)）**：
   - **机制与 `P0-120` 盲测**：固定 `V0` 中程、仅替换仓库出发步使 `P0-120` 总路程降低 **`7.96%` `[6.88%, 8.98%]`**（10,000 次 Bootstrap 0 次非正，`94/120` 胜）。按离线 `ana72` 选出的 **`s2_r5_spiral`**（P0 未参与选优）在 `P0-120` 取得 **`19.6092`**（`0.00%` 尺度极差），相对同请求上限对照 `ctrl_dev1_r7`（`20.6229`）总路程降低 **`4.92%` `[4.22%, 5.67%]`**（10,000 次 Bootstrap 0 次非正，`109/120` 胜；分层 `8.62% / 5.54% / 3.23%`；逐实例相对降幅均值 `5.66%`）。两臂各用 48 次 EoH 请求，实验臂 EoH Token 多 ~35%，另单列外部分析成本。
   - **方向二（`hetero-288` 5 因子测试床，`H-010`）**：单条 `s2_r5_spiral` 总路程 `7211.13` 低于旧 8 规则池逐实例最优 `7234.72`（注：扩池 VBS 单调性由定义保证）；在所测实例分布及规则池中，互补间隙随规模收窄（`4.69% → 1.87% → 0.49%`）；`rf_reg` 在 `cv12` 取得 **`+0.28% [+0.08%, +0.49%]`**（`p_boot = 0.0029`），在 `loro48`（`+0.08% [−0.13%, +0.29%]`）和 `loso3`（`−0.11%`）未见稳定收益；分离计时下 `rf_reg` 总耗时 **`10.940 ms`**（特征 `0.484` + 推理 `0.076` + 算法评测 `10.380`），高于固定 SBS **`10.436 ms`**（已删除原“RF 更快”误判）。

## 3 · 学术红线（答辩严守口径）

- **区分固定候选重采样与搜索运行稳定性**：`P0-120` 的配对 Bootstrap 衡量固定候选在 120 例上的逐实例不确定性；`b4` 与 `S2` 目前均为单次配对搜索，且 `S2` 由外部 Coding Agent 推动（EoH Token 多 ~35%，另含外部分析成本），尚不可宣称多随机种子稳健或完全无人值守自动化。
- **区分开发诊断与独立盲测**：共享 6 例含 4 个搜索期实例，仅作开发诊断；独立质量比较以未参与选优的 `P0-120` 为准，并保留仅按 `dev4` 选优的 `auto_dev1_r3` 在 `P0-120` 落后对照 `2.51%` 的反例。
- **方向二质量与计时边界**：`rf_reg` 仅在同分布 `cv12` 上取得显著质量增益（`+0.28%`），`loro48` CI 跨零、`loso3` 点估计为负；分离计时下 `rf_reg`（`10.940 ms`）慢于固定 SBS（`10.436 ms`）。逐点规则计时含现有评测包装拷贝开销，勿直接宣称与 `cw_merge` 的端到端速度对比。
- **CW 并行合并参照口径**：`P0-120` 上 `CW = 17.3570`、`R5 = 19.6092`（以 CW 为分母 R5 长 `12.98%`；以 R5 为分母 CW 短 `11.49%`）；`hetero-288` 上以 CW 为分母 R5 长 `9.10%`。结论表述为“已评估的并行合并参照领先当前逐点规则”。
