### 3.3 诊断与自动模板闭环对照（`b4_finding_only` vs `b4_control`）

- `runs/round_activity.py` + `runs/guided_search_b4.py` + `runs/measure_rounds.py`：每轮在 `s=1` / `s=1e-3` 重打分，维护三假设状态机并回灌 `evaluation.hypotheses`。
- 配对实测（`NN` 起点，均 24 请求 / 4 轮 / 0 provider 错误，共享套件 `C = 10.9197`）：

| 轮 | `b4_finding_only` 套件最优（对 C / spread） | `b4_control` 套件最优（对 C / spread 异常） |

| 1 | `12.0292`（+10.16% / 0.00%） | `11.8055`（+8.11% / 含 `spread >= 5%` 候选） |
