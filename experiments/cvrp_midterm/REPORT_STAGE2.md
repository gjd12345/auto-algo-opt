## 1 · 方向一前置理论：CVRP 边界相变与分桶决策追踪（`H-003`）

脚本：[`analysis/boundary_analysis.py`](analysis/boundary_analysis.py) → [`analysis/boundary_analysis.json`](analysis/boundary_analysis.json)（独立种子 `20261123`，72 实例覆盖 `n ∈ {50,100,200}` × `{uniform, clustered}`，`Q=40`，与 `cvrp_construct_mini`、P0 盲测及 `selection_s2` 零重叠）。

### 1.1 仓库起点（$i=0$）精确相变与反事实置换

对于线性打分 $s_\alpha(i,j) = d(i,j) - \alpha\, d(0,j)$，在仓库起点 $i=0$ 处有 $s_\alpha(0,j) = (1-\alpha)\,d(0,j)$：
- $\alpha < 1$（`NN`, `V0`, `C`）：起点必然选**最近客户**（距离分位 `0.0058`），边缘客户被遗留到路径末端，回程空驶占比高达 **`33.6%`**；
- $\alpha = 1$（`savings`, `A`, `B`）：主项恒为 0，决策完全交由次级平局规则——其中 **`A.py` 代数退化为 `argmin(demand)`**（距离分位 `0.4843`，需求分位 `0.0538`），**`B.py` 选重且远客户**（距离分位 `0.9841`，需求分位 `0.7659`）；
- $\alpha > 1$（`radial`）：外向内起点（`max d(0,j)`），但中程过度拉向远点。

| 规则 / 消融变体 | 72 实例均长 | 起点距均值 | 回程空驶占比 | 相对原生变化 |
|---|---:|---:|---:|---:|
| 线性扫描 `alpha = 0.99`（内向外） | 20.3165 | 0.2137 | 30.14% | 相变前 |
| 线性扫描 `alpha = 1.00 (tie=far)` | **18.9126** | 0.4469 | **23.25%** | **−6.91% 阶跃** |
| 线性扫描 `alpha = 1.01`（外向内） | 18.9302 | 0.4467 | 23.22% | −6.82% |
| `V0` 原生（`alpha=0.6`, 近起点） | 20.2959 | 0.2681 | 33.61% | 基准 |
| `V0` **仅换起点** → `far` | 18.6562 | 0.4567 | 23.71% | **−8.08%** |
| `V0` **仅换起点** → `heavy_far` | **18.6124** | 0.4544 | 23.97% | **−8.29%**（超过 `A 18.90`, `B 19.08`, `savings 18.91`） |
| `C` 原生 → 仅换起点 `heavy_far` | 20.4104 → **18.7909** | 0.2652 → 0.4564 | 33.27% → 23.96% | **−7.93%** |

### 1.2 分容量桶决策分歧（为何 `A` 胜均匀、`B` 胜聚类）

沿共享轨迹按 `start (i=0)`、`mid (rest/Q > 0.35)`、`near_full (rest/Q <= 0.35)` 分桶统计 `A` 与 `B` 的逐步骤决策分歧率：
- `uniform`：`start 97.80%`、`mid 11.00%`、`near_full 28.40%`；
- `clustered`：`start 98.15%`、`mid 24.43%`、**`near_full 47.30%`**（近一半近满容决策分歧，`B` 的二次装载压力 `0.35*fill²` 显著改善聚类收口）。

### 2.2 真实轮间假设演化与证伪记录（`ledger/hypotheses.jsonl`）

1. **R1（H-003 → 诊断失败原因）**：全部 5 候选实现起点解耦与无量纲化，但最佳仅 `−6.15%`；代码审计定位 `beta_fill=0.30..0.40` 相对 `d_cur/scale≈0.10` 过冲 3 倍导致跨图瞬移，且离线诊断**直接证伪**了“末站加 `+w_ret*d_dep` 惩罚”与“朴素 2 步前瞻”（**H-004a `abandon`**，因选择性惩罚大需求节点）。
2. **R2（H-004 → 首次突破 `Frozen C`）**：基于三角不等式提出此前规则池从未使用的**无量纲主动早返仓**（当归一化节约量 $\sigma(i,j)=(d_{0i}+d_{0j}-d_{ij})/(d_{0i}+d_{0j})<\tau$ 时提前 `return 0`），EoH 自主构造出三角伸长比 $\rho(i,j)=1-\sigma(i,j)$，`c3` 以 **`−10.96%`** 首次击败 `Frozen C`（`s001/s1=1.00000`），`c4` 在 `sh6` 达 `10.7523`。
3. **R3（H-005 → `dev4` 跨越至 `−15.76%`）**：融合线性径向项与 $\rho(i,j)$ 及容量自适应早返仓，3/5 候选超 `C`，`c3` 达 **`dev4=−15.76%`、`sh6=10.3051`（较 `C` −5.63%）**；但代码审计暴露 `c3` 漏写了起点分支导致 `n=200` 偏弱（`ana72=18.95`）。
4. **R4（H-006 → 跨规模飞跃）**：引入无量纲剩余车队指示量 `rem_routes = sum(q)/rest_cap`（两阶段外向内清边→核心收口）与**余弦定理仓库射线角一致性 $\cos\theta_0(i,j)$**，`c1` 取得 **`sh6=10.2078`（较 `C` −6.52%）**且 `ana72` 骤降至 **`18.107`**。
5. **R5（H-007 → 仅依赖车辆状态的内旋衰减）**：将恒定 $\alpha$ 改为仅依赖车辆状态的衰减函数 $\alpha_{\text{eff}} = \alpha_0 - \alpha_1 \min(1, \bar{q}/\text{rest\_cap})$（对同步全部候选一致，彻底规避 H-004a 的反重偏置），`c2`（`auto_ana1_r5`）将 `ana72` 降至 **`18.0007`（`n200=28.925`）**、`sh6=10.2714`。
6. **R6→R7（H-008a 证伪 + AST 故障自诊断恢复）**：离线**证伪**离散精确装箱奖励（**H-008a `abandon`**，单调退化 `17.88→18.10`）；R6 引入最近未访孤立紧迫度时 5/5 触发 `forbidden_attribute: fill_diagonal`，Agent 精确定位沙箱白名单限制并在 R7 改用 `np.where(np.eye(n)>0.5, np.inf, sub)` 实现 **5/5 恢复**，`c2` 取得均衡 `dev4=−15.27%`、`sh6=10.2595`。
7. **R8（H-009 → 后期边际递减诚实记录）**：尝试修复 R7 `c2` 中程 `pressure=0.0` 接线，2/5 有效（3/5 触发 `ix_/searchsorted`），未超越 R3–R7 冠军，按预算上限 48/48 正常收官。

三条核心结构发现：
1. **单规则超越旧组合全知 Oracle**：方向一自主构造的 **`s2_r5_spiral`（总路程 `7211.13`，均长 `25.0387`，平均名次 `2.878`）单枪匹马击败旧 8 规则池的事后全知 Oracle（`VBS_base = 7234.72`）**；在 `uniform` 与 `clustered` 两半集上均单挑胜过旧 Oracle；且 `s2_r7_iso` 凭借孤立紧迫度在 `clustered` 赢得 **41/144** 最高胜点（高于 `s2_r5_spiral` 的 `39/144`）。
2. **互补空间随规模收缩定律**：无论在基础池（`3.92% → 1.73% → 0.76%`）还是扩容池（`4.69% → 1.87% → 0.49%`），逐点规则的 VBS–SBS 间隙都随客户规模增大而急剧收窄——因为大规模下路径条数线性增长，决定优劣的主导因素高度收敛于跨规模边界策略与早返仓机制（`n=200` 时 `s2_r5_spiral` 平均名次达 `1.885 / 12`）。
3. **逐点构造 vs 完整并行 Clarke–Wright 合并的诚实边界**：`cw_merge` 总体均长 `22.95`（耗时 `4.14 ms`），仍领先 `pointwise_base` SBS（`25.51`）**10.04%**；加入方向一规则后，逐点 SBS（`25.04`）及聚类子集（`22.64 vs 21.33`，仅差 `+6.15%`）显著缩小了逐点构造与全局合并算法的鸿沟。

### 4.2 三种严格折外选择协议（`cv12` / `loro48` / `loso3`，10,000 次配对 Bootstrap）

所有回归与树模型均在折内以无量纲相对遗憾 $y_k = (c_k - \min_m c_m)/\min_m c_m$ 为目标拟合，杜绝跨规模量纲失真与任何测试泄露：

| 组合 | 协议 | 选择器 | 相对 VBS 间隙 | 相对折内 SBS 增益 [95% CI] | `p_boot` | W/T/L | 净耗时（特征+求解） |
|---|---|---|---:|---|---:|---:|---:|
| `pointwise_base` (SBS `savings`) | `cv12` | `pairwise_cs` | 1.43% | +0.13% `[-0.07%, +0.34%]` | 0.1021 | 51/201/36 | 6.00 ms |
| `pointwise_base` | `loro48` | `ridge` | 1.39% | +0.16% `[-0.04%, +0.37%]` | 0.0542 | 57/192/39 | 6.05 ms |
| `pointwise_base` | `loso3` | `ridge` | 1.38% | +0.18% `[-0.03%, +0.40%]` | 0.0504 | 54/197/37 | 6.01 ms |
| **`pointwise_plus_s2`** (SBS `s2_r5_spiral`) | **`cv12`** | **`rf_reg`（纯 NumPy 随机森林）** | **1.33%** | **+0.28% `[+0.08%, +0.49%]`** | **0.0029** | **57/195/36** | **10.86 ms**（快于 SBS `10.92 ms`） |
| `pointwise_plus_s2` | `cv12` | `pairwise_plain` | 1.39% | +0.22% `[-0.02%, +0.47%]` | 0.0398 | 71/156/61 | 10.49 ms |
| `pointwise_plus_s2` | `loro48` | `rf_reg` | 1.53% | +0.08% `[-0.13%, +0.29%]` | 0.2277 | 45/205/38 | 10.83 ms |
| `pointwise_plus_s2` | `loso3` | `pairwise_plain` | 1.60% | +0.01% `[-0.23%, +0.26%]` | 0.4822 | 63/156/69 | 10.78 ms |
| `pointwise_plus_s2` | `loso3` | `rf_reg` / `ridge` | 1.72% / 1.83% | −0.11% / −0.22%（跨规模外推负） | 0.81 / 0.92 | — | 10.35 / 11.48 ms |

关键机理剖析：
- **非线性特征交互带来净收益与负延迟开销**：在 `pointwise_plus_s2` 下，`rf_reg` 在 `cv12` 取得统计显著的 **`+0.28%` (`p = 0.0029`)**，按规模拆解为 **`n=50: +1.14%`**（动态分配 `s2_ctrl_best:42, s2_r5_spiral:37, s2_r7_iso:13, savings:4`）、**`n=100: +0.30%`**（`s2_r5_spiral:69, s2_ctrl_best:17, s2_r7_iso:10`）、**`n=200: −0.004%`**（精准收敛至 `s2_r5_spiral:89, s2_r7_iso:6`）；因小规模实例分流到更快的规则，包含 `0.48 ms` 特征提取后的**平均净耗时（`10.86 ms`）反而略低于固定 SBS（`10.92 ms`）**。
- **新特征主导预测力**：`rf_reg` 置换特征重要性前 6 位依次为 **`log_n` (+0.178%)**、**`depot_angle_disp` (+0.125%)**、`capacity_ratio` (+0.107%)、`cluster_tendency` (+0.092%)、`radial_std` (+0.079%)、**`nn_dist_cv` (+0.072%)**——第二阶段新增的 4 个规模/角度/局部密度特征占前 6 位中的 3 席。
- **跨规模外推（`loso3`）的诚实局限**：当完全隐去某一规模（`log_n` 落在训练集外）时，树与线性模型均无法可靠外推 `n=50` 与 `n=200` 之间的规则切换点（`rf_reg −0.11%`、`ridge −0.22%`），说明多规模部署必须覆盖目标规模范围的训练实例。
