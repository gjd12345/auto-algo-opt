# 605次实验阶段性基准

本文件夹保存两项相互衔接的研究：历史605次多岛搜索基准，以及本次在线装箱A/B/C先导实验。两部分分别提供学术报告、统计资料与图表，作为后续论文研究的起点。研究批次于2026年6月30日归档，本次整理日期为2026年9月26日。

## 两部分研究

第一部分分析605次历史有效运行的总体分布、进化轨迹和代表性数学规则。第二部分分析本次三组、三个配对种子、共900次评测的显式反思与在线经验实验。两部分研究对象和比较条件不同，不合并样本。

## 基准定位

本批次可作为“固定研究实例上的历史探索基准”和“代表性候选方法基准”。旅行商、容量约束车辆路径与在线装箱分别保留206、207和192次有效结果，中位数为6.212865、12.858850和0.036875。

三类问题的历史参考分别为6.560、13.519和0.0398。这些参考来自早期实验，其模型或搜索投入与当前批次存在差异。因此，相对改善描述历史进展，不识别某个机制的独立贡献。共享历史也使605次运行不等于605个独立重复。

在线装箱的最优超额率相对改善为83.07%，在同一下界及舍入参考下对应平均箱数约下降3.18%，二者不可混用。

## 后续沿用原则

保留本目录中的历史数据和定义。新增实验另设文件夹，明确相对于本基准改变了哪些条件，并同时报告典型结果与最优结果。若要证明共享经验、搜索深度或特定规则的贡献，应先统一比较条件，再进行预先约定的对照。

本次整理只分析原有资料，未增加优化运行，也未使用新的独立测试成绩。历史正文未混入后续九运行数据；本次A/B/C实验在上述配套子目录中单独报告。
