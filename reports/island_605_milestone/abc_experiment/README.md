## 两批实验

三组分别为直接依据事实制定计划（A）、强制形成并使用证据支持的研究笔记（B），以及进一步积累和读取本运行较早轮次经验（C）。首批每组每种子独立完成四轮，共九次运行、900次实际评测。A、B、C的终点超额率均值分别为0.018077、0.031157和0.007378；C在处理开始前已领先，不能把终点差直接归于经验。

第二批使每个配对种子的三组共享一次实际首轮，再分别完成75次评测。三个共同首轮与九个后续分支合计750次实际评测；按每分支100个位置记录共有900个预算位置，不能把共享首轮重复计为新的实际评测。A、B、C的终点均值分别为0.009256、0.007948和0.016568。B仅在一对中优于A；C虽在两对中优于B，但另一对明显较差。第三对中B组分析主体的模型条件无法与其他组逐项核对，因此三对结果仅作探索性描述，不用于严格处理效应推断。

两批均使用已暴露的五条训练物品流，没有使用独立测试资料。外层分析模型的完整成本不可得，不能据已知候选生成词元判断总成本效率。
