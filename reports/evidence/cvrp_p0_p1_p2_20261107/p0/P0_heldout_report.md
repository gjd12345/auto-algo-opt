# CVRP P0 独立留出验证

**训练集最优 C 在 50 客户留出集上仍优于最近邻，但 A 的平均距离更低。** 在 100、200 客户上，A 和 B 保持了较稳定的改善，C 的优势则收窄到与基线难以区分。

## 设计与口径

评测来源为提交 `f0cd00fd` 的三场搜索。先冻结 A、B、C 和 ProblemSpec 最近邻基线的源代码，再生成留出数据。代码按仓库计算身份时使用的 UTF-8/LF 形式核验，A、B、C 的 SHA256 与搜索导出一致。以同一个 CVRP Evaluator 评测，未发起模型请求或重新搜索。

50、100、200 客户各 40 个实例。50 客户与开发集采用相同的数据生成规则和车辆容量，后两组改变客户规模。120 个实例使用互异的确定性种子，未发现与开发集重复的实例。四个算法在每组的相同实例上比较，480 个算法×实例均得到有效距离。

距离为每个实例全部路线的欧氏总距离。相对改善定义为参考算法与候选的平均距离差除以参考算法平均距离，正数表示候选更短。95% 区间在同一规模内按实例配对重采样 20,000 次，使用百分位法。区间描述给定冻结算法与数据生成规则下的样本不确定性。

## 训练最优 C 在留出集上的排序

| 客户数 | C 相对 A 改善 [95% 区间] | C 对 A 胜/平/负 | C 相对 B 改善 [95% 区间] | C 对 B 胜/平/负 |
|---:|:---|---:|:---|---:|
| 50 | -3.97% [-6.71%, -1.34%] | 13/0/27 | -0.17% [-3.13%, +2.70%] | 19/0/21 |
| 100 | -8.25% [-10.30%, -6.23%] | 4/0/36 | -7.74% [-9.79%, -5.79%] | 2/0/38 |
| 200 | -11.98% [-13.84%, -10.24%] | 0/0/40 | -10.47% [-11.94%, -9.03%] | 0/0/40 |

- **50 客户。** C 比最近邻短 7.63%，赢 37/40，说明其训练收益有一部分能迁移到同分布留出实例。A 比最近邻短 11.15%，同样赢 37/40，但平均距离更低。C 比 A 长 3.97%，配对区间为长 1.34% 至 6.71%。C 与 B 的均值相近，配对区间跨零。
- **100 客户。** A 和 B 仍分别比基线短 10.12% 和 9.69%，C 的改善降到 2.70%。C 对 A 只赢 4/40。
- **200 客户。** A 和 B 在全部 40 个实例上优于最近邻。C 虽然赢基线 21/40，平均距离却高出 0.33%，配对区间跨零。C 对 A 和 B 均为 0/40，说明在这组规模下，胜率和均值必须结合解读。

## 对下一步研究的含义

开发集上的冠军不能直接作为部署或论文比较的唯一候选。在这 120 个留出实例上，A 的均值在三个规模都最低。C6 仍是值得做机制研究的案例。其结果同时呈现同规模泛化与规模迁移变弱，适合用受控版本区分掩码、容量惩罚和全局竞争。

本次三组规模均由同一个 CVRP 生成器产生。结论适用于此类随机欧氏 CVRP，尚无真实路网或其他需求分布的证据。由于本次留出结果已经可见，后续若以它设计或调整 V0–V3，应另保留一批未参与机制选择的实例供最终检验。
