# P2：Memory 与外层数学指导的 2×2 试验

**显式数学指导在本批开发集上有一致的正向差值，独立留出上的差值明显收窄。** Memory 主效应在开发侧与留出侧方向相反。三个配对种子不足以确认稳定的性能收益或协同效应。

## 运行设置

三个种子区组，每个区组各运行 A、B、C、D 四臂，每个会话三轮。每个种子的四臂共享相同的六个 50 客户开发实例。EoH、DeepSeek 官方 deepseek-flash、搜索预算、评测器、继承模式和事实反馈通路一致。Memory 开启的会话各自从空库开始。

数学指导开启时，外层 Codex 把明确的数学观察与待验证改动写入 Plan。关闭时，外层仍根据同等的分数和合法性反馈进行直接代码探索。内层 EoH 在所有组都可使用模型已有的算法知识。因此这里测量的是两种外层指导政策之间的差异。三组由同一个外层操作者在可见的条件下完成，Plan 内容和模型生成随机性仍然可能影响差异。

12 个会话均完成，共 156 次真实 API 请求，全部 HTTP 200。204 次 solver 尝试包含基线和继承候选复评；120 个新候选中有 104 个有效，120 条实际生成请求均可核对到完整 Round Context。最终代码冻结后，额外在同一组 40 个独立 50 客户实例上评测。该组数据在第 3 轮结果可见前冻结，未用于制定 Plan；12 个最终候选与最近邻均完成 40 个实例。

## 配对因子差值

单位为百分点，正数表示平均距离降幅增大。Memory 主效应为 ((B−A)+(D−C))/2，数学指导主效应为 ((C−A)+(D−B))/2，交互为 D−C−B+A。

| 数据 | 种子 | Memory | 数学指导 | 交互 |
|:---|:---|---:|---:|---:|
| 开发 | 20261201 | -3.67 | +0.57 | +0.99 |
| 开发 | 20261202 | +1.47 | +3.73 | -0.94 |
| 开发 | 20261203 | -1.23 | +4.69 | +0.02 |
| 开发 | 均值 | -1.14 | +3.00 | +0.02 |
| 留出 | 20261201 | -0.93 | -0.75 | -3.24 |
| 留出 | 20261202 | +2.26 | +1.40 | -3.20 |
| 留出 | 20261203 | +1.06 | +0.05 | +3.52 |
| 留出 | 均值 | +0.80 | +0.23 | -0.97 |

- 数学指导的开发侧三个配对差值都为正，平均 +3.00 个百分点。留出侧平均 +0.23 个百分点，三个差值分别为 −0.75、+1.40 和 +0.05。训练侧结果未转化为稳定的留出优势。
- Memory 的开发均值 −1.14 个百分点，留出均值 +0.80 个百分点，两侧都出现反方向的种子。Memory 开与关各有 52/60 个有效候选。交互在开发侧接近零，留出侧随种子换方向。

## 实际采用与后续决策

数学指导开启的 18 轮中，按最佳有效候选与本轮 Plan 的人工源码核对，有 10 轮对齐、6 轮部分对齐、2 轮偏离。10 轮对齐中有 7 轮刷新当前最优、3 轮没有。其余 8 轮保留为原假设证据不足。这是可观测的筛选口径；改进不能单独归因于假设指定的机制。关闭组的 18 轮是宽泛直接探索，记为 unknown，不能与开启组的对齐率直接比较。

开启组 12 次后续 Plan 均使用本会话的评测与代码修改研究建议。例子包括 C 在种子 20261203 中识别到正的公共除数不改变排序，将下一轮焦点转向真正影响排序的需求项。生成代码进一步把线性需求比改成平方，分数下降，但偏离了系数单改动，因此只给部分对齐。种子 20261202 的 C3 获得更好的分数，却重写了路线内评分，未检验原计划的单系数假设。未把这两次改进登记为数学假设已验证。

Memory 发布 8 条 insight，24 条完成的生成请求携带至少一条。在种子 20261201 的 D 中，第 1 轮有三个 lexsort 候选被拒。第 2 轮读取相应经验，两个生成请求均携带该条目，两个候选均通过评测，但分数未超过 incumbent。因为下一轮 Plan 同时提出了接口建议，这个案例说明记忆通路工作，无法单独估计它对合法率的贡献。

## 结论范围

该试验完成了一个有真实 API 和独立留出结果的配对因子试跑。三轮设计主要覆盖冷启动和两次反馈，Memory 最多有两轮可被消费。三个配对种子不适合给出精确的总体效应、正式显著性或强因果结论。Plan 由同一外层操作者制定且未盲法，数学指导开关改变了提示内容和后续决策。当前可支持的结论是显式指导与开发侧进展相伴，但还没有证据表明这套指导政策在留出侧稳定优于直接探索。
