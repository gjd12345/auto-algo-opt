## 1. 实验设置

大模型每次只写一个短函数。官方评测器在固定实例上给出最小化目标值，再把较好个体送回模型继续改。单次运行：种群 6，代数 8 或 16，算子 `e1,e2,m1,m2`。并行 5 个 gen=8 岛加 3 个 gen=16 岛。每步 RAG 注入 2 张策略卡。

| 算子 | 模型指令 |
|---|---|
| `e1` | 写出与父代形态不同的新算法 |
| `e2` | 抽出父代共同骨架后再写新算法 |
| `m1` | 在一个父代上做结构修改 |
| `m2` | 改主要数值参数 |

基线：TSP 6.56，CVRP 13.519，BP 0.0398。改善率 = `(基线 − 目标值) / 基线`。

## 2. 三类问题，每类 3 个较好代表

外围循环由评测器固定。模型只设计一步选择规则。

### 2.1 旅行商构造 `tsp_construct`（206 次，基线 6.56）

接口：`select_next_node(...) -> int`。50 点、8 实例、`seed=2024`，平均回路长度。

| 代表 | 机制 | 目标值 | 相对基线 |
|---|---|---:|---:|
| T1 滚动估价 | 当前边 + 剩余点最近邻滚动路径 + regret + 长边惩罚，权重随剩余点数变化 | 6.00393 | 8.48% |
| T2 终点比例 | 用到终点的距离占比压低过远插入，并用邻边均值惩罚过长当前边 | 6.07352 | 7.42% |
| T3 线性组合 | `score = d(current,u) − 0.5 · d(dest,u)`，近且远离终点者优先 | 6.07672 | 7.37% |

T1 来自 `island_5/high_gen_tsp_construct/..._r27`。第 0 代最优 6.983，第 8 代 6.00393。选择器不做边交换。

### 2.2 带容量车辆路径构造 `cvrp_construct`（207 次，基线 13.519）

接口：`select_next_node(...) -> int`，可返回仓库。50 客户、容量 40、16 实例。

| 代表 | 机制 | 目标值 | 相对基线 |
|---|---|---:|---:|
| C1 Savings 切换 | 仓库 farthest-first 开线；容量充足时用 Clarke–Wright savings 选点；容量紧时近则继续、远则回仓 | 12.35639 | 8.60% |
| C2 后悔值 | 仓库 farthest-first；途中比较「现在服务」与「留到下一车从仓库出发」的代价差 | 12.42319 | 8.11% |
| C3 容量加权 | 仓库 farthest-first；途中 `α·d(current,u)+(1−α)·d(depot,u)`，`α` 随剩余容量变化，过远则回仓 | 12.43290 | 8.03% |

C1 来自 `gen16_island_1/..._g16_r7`。第 0 代 13.283，第 16 代 12.356。

### 2.3 在线装箱打分 `bp_online`（192 次，基线 0.0398）

接口：`score(item, bins) -> ndarray`。Weibull 流、箱容 100。目标是相对 L1 下界的 excess，`(所用箱数 − L1) / L1`。

| 代表 | 机制 | 目标值 | 相对基线 |
|---|---|---:|---:|
| B1 分段残差 | 指数利用率奖励，减去残差落在 `(0, 2·item)` 的二次惩罚；恰好装满不罚 | 0.00674 | 83.07% |
| B2 半箱偏离 | `1/residual^1.5` 奖励紧致装箱，再减去残差偏离半箱容量的项 | 0.00694 | 82.56% |
| B3 谐波峰 | `1/residual` 加残差约 50% 均值处的高斯峰，兼顾紧拟合与预留空隙 | 0.00714 | 82.06% |

B1 来自 `island_1/high_gen_bp_online/..._r27`。前 7 代最优停在 0.02324，第 8 代一次改写到 0.00674。该 83% 是 excess 指标改善，不是箱数下降 83%。

## 3. 大模型怎样进化

1. 提示里放入 API 契约和 2 张策略卡，例如 TSP 的 regret / 长边惩罚、CVRP 的 farthest-first / savings、BP 的残差多项式。
2. 第 0 代写出 3–6 个可运行函数并评测。TSP 第 0 代最优约 6.98，CVRP 约 13.28，BP 约 0.023，后两者已优于基线。
3. `e1/e2` 换骨架：TSP 加入剩余路径滚动，CVRP 把途中规则换成 savings 或后悔值，BP 把利用率与残差惩罚拼成一段公式。
4. `m1/m2` 改阈值：CVRP 的 0.4 / 0.7，TSP 的 0.5 与动态权重，BP 的残差区间。
5. 评测器只认目标值。极差个体被丢掉。后到的岛从共享池读到已验证代码。

全批次：TSP 中位 6.213（5.29%），CVRP 中位 12.859（4.88%），BP 中位 0.0369（7.35%）。改善超过 5% 的运行共 317 次。上表 9 个是机制去重后的头部代表，不是 317 条重复记忆。
