### 路线评测和算法结果

- **输出可查看的实际路线。** 全解评测统一核验客户覆盖、容量、路线端点及适用车辆数约束，从同一距离矩阵重算路程。逐点规则复用构造语义或轨迹适配，对照现有正式评测做逐实例核验。共享 6 例的 R5 均长约 **10.2714**，同时核验主动回仓对应的路线及装载变化。
- **覆盖原稿中的 7 个参照。** 提供 NN、逐点 savings、R5、R7、并行 CW、CW+2-opt、CW+relocate+2-opt。局部搜索用明确的步数或时间预算，让输出可比较。对较大外部套件按登记的预算执行。
- **统一分数与测时。** 新套件采用逐实例相对差距 `(L_i−R_i)/R_i` 的均值，分规模、分工况展示。记录预处理、求解、独立校验和状态。页面能看到完成率、求解时间 P50/P95 和覆盖范围。不同算法的时间和质量比较使用同一实例子集及同一预算，展示该子集的样本数。
- **覆盖论文两条主线。** 能查看固定算法的结果和改动前后差异，也能比较单一最佳规则、逐实例 Oracle 和有折外评测记录的可部署选择器。三种结果注明各自使用的实例与信息范围。以逐实例记录为展示数据，保留方向二已有的正负结果。

旧历史计时仅用于标定起点。n=200 的 CW、R5、R7 P95 分别约为 11.0、24.4 和 32.4 ms，每例采用三次最小值。新发布使用统一计时口径提供原始结果和分位数。

## 3. 知识库和证据组织

沿用现有 `build / validate / validate-release / search / read` 与冻结发布。试验相关的 CVRP 知识完整纳入同一版，网页和 CLI 读取同一发布索引。现有 297 条记录继续用稳定 ID、原有问题族和来源。对于旧 `eoh_map` 与新路线接口，页面按各自适用范围呈现。

| 内容 | 本次完整覆盖 |
|---|---|
| 构造和合并 | NN、逐点 savings、并行 Clarke–Wright、Sweep 与 Petal 等聚类构造、最小增量或 regret 插入。描述候选、增量公式、状态变化及约束。 |
| 路线改进 | 路内 2-opt、Or-opt，路间 relocate、swap、2-opt*，Granular Tabu、VNS 和破坏重建。记录可改动的路线、可行性和预算条件。 |
| 本地规则及数学观察 | H-001、H-003、C、R5、R7，以及已记录的其余研究发现。给出推导、规则对应字段、实验范围和原始证据。与选择相关的发现能直接打开对应对照。 |
| 适用条件与观测边界 | 区分标准 CVRP 与有时间窗、带回程取货等变体。区分文献给出的步骤、本机或本仓库实现、已产生可复算结果的算法。失败观测放在其关联方法或工况下，帮助解释结果。 |

卡片的正文、源码引用和实验结果通过稳定 ID 关联。实验结论挂到真实的 `suite_id`、`run_id`、算法版本、指标和原始结果。公式配上变量含义与适用前提。实现卡可打开固定提交源码。摘要或派生条目按实际证据标注。正文沿用五个必备章节，发布的 Markdown 用 UTF-8、LF 字节计算 `content_sha256`，元数据单独校验。

检索覆盖标题、正文、方法别名、问题族、范式和证据类型。精确 ID 可直达，结构化过滤可复用。用户查完整 CW 时能看到合并步骤及对应结果，查 DARP 或 Solomon 时能识别它的约束语境。2-opt、插入、回仓、H-003、R5 等中文或英文查询可通过同一索引定位。卡片数量以方法覆盖和证据质量决定。

## 4. 前端展示

**前端是正式交付物。** 在现有 `knowledge_tools/dashboard.py` 的离线网页发布基础上扩展成统一入口。现有知识搜索、详情阅读和深链接入新导航。基准、卡片和实验数据由同一套发布索引导出，浏览器直接比较已发布结果。页面支持从共享链接返回同一版本、套件、实例和算法选择。

| 页面 | 主要布局和操作 | 必须呈现的数据 |
|---|---|---|
| **问题与基准** | 顶部选择套件与用途，侧栏筛规模、工况及来源，主区是实例列表和空间预览。选择实例后进入路线比较。 | 仓库位置、客户坐标和需求、容量、工况、来源、参考值与距离规则。实例表与散点预览联动。 |
| **算法知识** | 搜索与筛选在左，方法列表在中，上下文详情在右。详情有公式、步骤、适用条件、实现或证据，能从相关实验回跳。 | 明确标注资料层级。提供数学卡、算法实现、对应实例或工况的证据。 |
| **路线对比** | 同一实例选两种算法并排查看。两图用相同坐标范围和仓库符号。点选路线可查看访问顺序与载重。可在总览与逐步动作之间切换。 | 各自的路线数、总路程、相对 gap、用时、完成状态。逐点规则的主动回仓能在动作或轨迹中定位。 |
| **实验结果** | 选择同一套件和预算后比较算法。提供可排序表格、分规模或工况对比和质量–用时图。点选图表能下钻到实例结果。 | 样本数、参考值与指标口径、完成率、质量与用时分位数。单算法、Oracle 与折外选择器各自有清楚标签。 |

展示以 CVRP 坐标、路线和已算出的指标为主体。每张图有单位、图例和可对应的数值表。路线与容量用数据绘制，页面交互只需要提供帮助用户定位实例、算法和证据的控件。桌面优先支持并排比较，窄屏下保留筛选、阅读和路线详情。前端与 CLI 从同一批逐实例记录计算或读取汇总，避免展示口径独立演化。

## 5. 一次交付与实际验收

**数据与页面从开始同步做，最后统一发布。** 实例、算法、卡片和实验记录先对齐关联 ID。页面在共享的真实数据上逐步连通详情与跳转。套件、基线结果、完整 CVRP 卡片和可浏览前端同时进入该次发布。

编排和检查面向三个实际场景。

1. **展示单条算法如何产生路线。** 在页面打开一个公开可浏览的 CVRP 实例，同时选择 R5 和并行 CW。并排显示两条轨迹的路线、分数和用时。可以在 R5 里定位一次主动回仓，从任一方法跳到对应卡片及其源码。
2. **解释方法为什么在某些工况表现不同。** 从 H-003 或 C 的尺度观察卡打开对应结果，切换实例或工况，查看数据、公式、推导和实验观察。从页面能复算引用的分数和汇总。
3. **展示互补性和选择效果。** 在同一套件和预算下查看单一最佳规则、Oracle 和折外选择器。可打开组成该统计的实例，检查选择失误的方向与代价。图表、表格和导出记录使用同一批结果。

验收集中在上述真实操作，以及确保结果可用的实例清单、路线合法性和分数对齐。实现顺序以实际访问和演示效果为准，功能范围按一次完整发布安排。
