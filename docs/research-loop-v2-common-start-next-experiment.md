# 共同首轮分叉的下一轮 A/B/C 诊断方案

## 研究问题与解释范围

本轮要判断：在**完全相同的实际首轮搜索历史**之后，强制形成证据绑定的研究笔记是否改变后续搜索（B 相对 A）；在此基础上，仅复用本分支较早轮次经验是否继续改变后续搜索（C 相对 B）。估计对象是第二至第四轮的增量，而非九运行先导批次的终点差。三个配对种子只用于验证流程与估计方差，不作显著性或普适有效性声明。

沿用已暴露的五条在线装箱训练流、同一目标和现有候选生成配置。独立测试资料保持锁定。第一轮使用每个种子的一次中性共同搜索，必须在任何组别特有的研究笔记、经验写入或下一轮计划之前冻结。只有同一份候选、种群、逐实例结果、当前最优规则、身份与证据可在三个分支中逐项复核，才能继续。

诊断种子由固定文本 `island605_bp_common_first_round_v1/three_seed_diagnostic` 的 SHA-256 摘要按顺序取前三个四字节无符号整数，冻结为2257253183、783449680、1455563558。它们不依据上一批的终点排名选择。候选生成模型继续固定为 `qwen/deepseek-v4.1-flash`；模型参数、问题实例、评测规则、搜索参数和预算均沿用已冻结的上一批配置，任何必要变更须在首个共同首轮请求前另行记录，且整批统一。

## 处理、预算与成本

| 条件 | 固定规则 |
|---|---|
| A | 阅读统一规则生成的对比材料，直接形成下一轮计划 |
| B | 阅读同样结构、字段和选择规则的材料，先提交证据绑定的研究笔记，再形成计划 |
| C | 与 B 相同，并从空白经验库开始，仅发布和使用本分支更早轮次形成的经验 |
| 主预算 | 每个分支在记账轴上100次评测：共同首轮25次，分叉后每组75次，后者分为三轮、每轮25次 |
| 实际总量 | 若三个配对种子全部完成，真实评测次数为3×(25+3×75)=750次；三个分支的预算轴合计仍为900个位置。两者必须分开报告 |
| 成本 | 分别报告候选生成模型成本、外层分析成本、请求数及耗时；不可取得的外层成本记为不可得，不按零处理 |

三个种子的组别处理顺序分别固定为 A→B→C、B→C→A、C→A→B。顺序平衡不代替分析语境隔离；每个分支仍须由仅能看到共同首轮及本分支资料的独立分析上下文处理。

共同首轮的25个质量轨迹点在三个分支的图中相同；不得将这些共享点算作三个独立运行。共用历史的生成成本报告一次，分支成本分别报告。失败、中断、基准评价及已有候选重评继续占用评测预算。三个分支任一出现身份缺失、预算错误或证据损坏，该配对单列为失败，不按正常提前停止补平曲线。

## 执行与验收顺序

1. 建立只读共同首轮导入：保留原评测身份及来源，明确记录导入关系；禁止手工重造候选或评测编号。先用已有训练事实做零模型请求验证，再建立新的共同首轮。
2. 验证三个分支的处理前候选、种群、逐实例事实、最优规则和预算账本逐项相同。C 的经验库为空；A、B 的对比材料构造规则和字段相同。
3. 三组使用相互隔离的分析语境，只读取本组分支及允许的共同首轮资料。固定分析主体的模型身份和处理顺序；如精确外层成本不可得，保留缺失状态。
4. 先执行一个配对种子的可行性运行，检查完整的“事实—材料—笔记（B/C）—下一轮计划—实际候选—评测结果”链，以及经验发布、完整读取和实际使用。通过后按预定三个种子完成诊断，不根据首个种子的质量排名改变配置。
5. 对每轮计划和候选分别记录指定的改动、实际父代、实际变化、逐实例效果与无法确认之处。严格单因素候选与广泛改写候选分开解释，不从目标改善反推计划得到执行。

## 预先固定的报告方式与停止条件

主比较按共享首轮后的评测序号展示分支最优超额率、第二至第四轮过程曲线面积（第26至100次评测后最优超额率之和）、固定终点与逐实例箱数；同时列出有效率、行为重复率和生成尝试数。B−A 和 C−B 均按配对种子报告原始差及均值，不把同一首轮或五条训练流误作独立重复。对 C−B，首轮后改善差与终点差均报告；三对样本不做确认性显著性检验。扩大实验的质量信号预设为：至少两对种子在所比较处理下的终点方向一致，且平均终点改善达到0.0005（约相当于五条物品流合计减少5个箱）；这只是决定是否估计正式样本量的门槛，不是确认性成功判据。

若共同首轮不能逐项验证、导入身份被重造、分析语境发生跨组读取、C 使用外部经验、A/B 材料规则不同，或成本缺失被当作零，则停止该配对，不形成处理效果结论。完成三种处理各三次且证据链可审计之后，才评估是否有值得扩样或写入论文的结果。正式样本量、选择规则和一次独立测试须另行冻结，不能依据本诊断的训练排名决定测试时机。

截至本文件形成时，只完成原九运行的首轮差异与计划落实核验；**共同首轮导入尚未完成，新一批真实 A/B/C 搜索尚未开始**。本方案不把离线核验当作新实验结果。
