# 在线经验内容的下一轮训练诊断方案

## 研究依据与问题

前两批在线装箱三组诊断已完成。共同首轮配对批次消除了处理前首轮差异，但未得到跨配对稳定的质量优势；一组分析主体的模型条件还无法与其他组核对。尤其在一个配对中，经验虽被完整读取，搜索仍长期停留在较弱规则附近。因此，下一轮不重复宣称“经验有效”，而检验经验内容相对于同量近期事实是否改变后续问题和搜索路径。

本轮是训练资料上的机制诊断，不作显著性或泛化声明。五条在线装箱物品流、目标函数、候选生成模型和评测规则沿用已冻结的共同首轮实验；不访问独立测试资料，不根据其结果调整方案。

## 三种处理

每个配对种子先完成一次中性共同首轮，冻结25次评测的全部候选、逐实例结果、当前最优规则与比较材料，再分为三条相互隔离的后续分支：

| 组别 | 第2至第4轮的分析材料 | 增量处理 |
|---|---|---|
| R | 当前轮统一证据包与证据绑定研究笔记 | 笔记形成后直接制定下一轮计划，不额外检索过去轮次 |
| F | 与R相同，另附本分支较早轮次的事实摘录 | 只摘录原始观察及其证据与适用状态，不加入提炼的建议 |
| M | 与R相同，另附本分支较早轮次提炼的经验 | 仅使用本运行内形成、证据绑定并声明适用边界的经验 |

F与M均从空白开始。共同首轮结束后，两组各自从相同事实形成研究笔记，并分别产生事实摘录或经验；这些材料最早从第二轮起使用。F的摘录和M的经验均按已冻结的排序规则选择，来源只限本分支更早轮次，不能引用其他组或其他种子。两者的附加材料采用相同长度上限，记录实际输入长度和可取得的模型词元；长度控制不保证语义信息量完全相等。

在首次新增评测前进一步固定材料口径：F与M的历史材料均只提供给负责反思和制定计划的分析主体，不直接注入候选生成模型。三组的候选生成模型只接收同一结构的近期评测反馈和各自形成的计划。由此，M相对F检验的是不同历史表述经分析主体影响计划的作用，不检验向候选生成模型直接注入经验的作用。

材料选择不依据目标优劣。每次选择本分支最近一个具有可用记录的较早轮次，向前追溯至首轮为止；同轮并列按记录原有顺序。F仅取该轮已接受研究笔记的`observations`及其证据引用，不取假设、下一轮建议或新写的总结；M仅取该轮已发布的经验正文及原有适用边界，没有发布则继续向前追溯。每次附加正文上限为1200个Unicode字符，不截断单条观察；超过上限的单条观察按原顺序跳过，经验正文超过上限则不得发布。材料来源、原文件摘要、实际长度和送达分析主体的输入摘要逐轮保存。两组使用同一长度上限，但实际信息量与词元仍可能不同，必须分别报告。

主要比较为M相对F：提炼经验是否比阅读近期事实产生不同且可执行的研究问题，并改善第二至第四轮的搜索。F相对R只用于诊断额外历史事实本身的作用；M相对R不是单一机制对照。三组均须提交同样结构的证据绑定研究笔记，避免把“有无笔记”与“历史材料形式”混为一项处理。

## 预算、种子与分析主体

每条分支在预算轴上100次评测：共同首轮25次，后续三轮各25次。三个配对全部完成时，真实评测数为3×(25+3×75)=750，分支预算位置共900个。候选生成尝试、基准重评及中断尝试均占用预算。主守恒资源仍为评测次数；候选生成模型和外层分析模型的词元、请求与耗时分别报告，不得将缺失成本记为零。

诊断种子由固定文本 `island605_bp_memory_content_control_v1/three_seed_diagnostic` 的SHA-256摘要前三段四字节无符号整数确定，依次为2658045112、2210285944、3138250455。种子顺序不依前两批终点选择。组别执行顺序分别为R→F→M、F→M→R、M→R→F。

全部分析主体使用同一明确标识的模型与配置，分别从无其他组资料的新语境启动。启动记录必须能核对模型标识；若某分支临时改用不同模型，该配对退出处理差比较，只保留描述性观察。分析主体只读取共同首轮和本分支事实，不读取其他组计划、笔记或结果。候选生成模型维持 `qwen/deepseek-v4.1-flash`；外层分析主体固定为 `gpt-5.5`。若该模型不可用，不以其他模型静默替换，而是在任何新评测前统一修订本方案。

## 预先固定的观察与判定

主结果为第26至100次评测后的最优超额率轨迹、该区间最优超额率之和、固定终点及五条流的终点箱数。每一配对报告M减F、F减R的原始终点差及过程差，不把五条训练流或共享首轮当作独立重复。

内容层面逐轮判定：附加材料是否确实来自较早轮次、是否提出超出现轮反馈的具体可检验问题、下一轮计划是否引用该问题、实际较优候选是否符合所指机制。局部改动与广泛改写分别解释。记录有效候选率、行为重复率、附加材料长度和实际模型消耗，防止把覆盖率或较长输入误作质量收益。

是否值得扩大样本的描述性门槛沿用前批：至少两对种子在M相对F的终点方向上改善，且平均改善达到0.0005。即使达到门槛，也只进入正式样本量设计，不构成确认性成功。若模型身份、共同首轮身份、材料来源、预算账本或阅读链不能复核，该配对停止，不用终点补算。首个配对只验证可行性；流程通过后按既定顺序完成其余两对，不依据首个配对的质量结果挑选后续种子。

## 执行与报告约束

先完成只读共同首轮导入及三组处理的最小接口调整，随后进行一次无新增模型请求的验证；通过后开始第一个真实配对。任何失败先保留已有事实并修复可恢复的流程问题，不重算或替换不利结果。整批最多新增750次真实评测。完整三对诊断或出现具有代表性的可追溯机制结果后，才决定是否修改学术报告；无论质量方向如何，都保留负面与不确定结果。独立测试资料持续锁定。

截至方案冻结时，本轮尚未开始；前两批的统计和结论不随本方案修改。
