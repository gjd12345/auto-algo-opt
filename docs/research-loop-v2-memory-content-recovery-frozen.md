# 在线经验内容三组诊断：故障恢复后冻结合同

## 研究问题与既有成本

本次仍比较 R（证据绑定反思）、F（反思加本分支较早轮次的事实摘录）、M（反思加本分支较早轮次提炼的经验）。主要问题是 M 相对 F 能否形成不同、可执行的研究问题，并改善第二至第四轮搜索；F 相对 R 只诊断额外历史事实文本的作用。三组均有相同的当前评测证据和笔记结构；历史材料仅交给分析主体，不直接注入 EoH。结论限于冻结的在线装箱五条训练流，不读取 heldout。

先前首次执行消耗 25 次真实 solver 评测，因 `EVIDENCE_STORAGE_FAILED` 无法继续。该批事实与失败终态保存在原工作区，不用于新三组的质量比较，也不从总成本中抹除。用户随后要求继续；本轮据此把**累计真实评测上限固定为 775 次**：先前中止成本 25 次，新的三配对最多 750 次。再发生无法形成可继续终态的技术故障时，立即停止，不自动再提高上限。

## 不变的实验因素

种子依次为 `2658045112`、`2210285944`、`3138250455`，执行顺序分别为 R→F→M、F→M→R，不根据目标结果调整。每个种子只进行一次中性共同首轮，真实调用上限 25 次；随后将同一首轮评测 ID、种群快照及全部哈希导入三个独立新会话。每条分支的预算轴为 100 次，后续三轮各最多 25 次，所以新实验完整执行时真实调用最多 `3×(25+3×75)=750` 次。候选生成模型、五条流、目标、EoH 搜索参数、初始 Plan 和运行时身份在三组一致；候选生成模型为 `qwen/deepseek-v4.1-flash`。

只有共同首轮的官方任务终态为 `ROUND_BUDGET_EXHAUSTED`、正式收集产生 25 条精确身份记录且可正常继续，才允许导入三个分支。`STARTUP_FAILED`、`EVIDENCE_STORAGE_FAILED`、来源或哈希不一致均为技术失败；不能借由复制事实、改数据库终态或重做不利结果绕过。每轮检查账本，累计物理调用包括先前失败的 25 次，而三个分支导入的共同首轮只计一次。

## 有界分析材料与独立决策

外层分析模型固定 `gpt-5.5`，每组每轮使用独立的 CLI 语境。分析模型只收到由同一算法从官方已收集事实生成的结构化摘要，最多 16000 个 Unicode 字符，含原始文件引用和 SHA-256、各候选精确评测 ID、逐实例表现、三类确定性对比槽、实际来源与行为关系、有效性、成本和停滞状态。生成摘要时核对比较材料与执行差异文件的哈希；超长或核对失败立即停止，不截断造成选择偏差。三组相同阶段采用相同摘要算法；内容随各组真实结果分化。

分析模型不运行工具或直接操作 Session，只返回 JSON 决定，由固定传输程序核验并提交。每轮评测后先产生证据绑定研究笔记；下一轮制定 Plan 时，三组共同看到上一轮笔记的假设与下一问题，但不重复展开整份原始记录。F 另外看到本分支更早轮次的原始观察摘录；M 另外看到本分支正式发布、完整读取并核验来源的经验正文。F/M 采用相同的 1200 字符历史材料上限与既定最新可用轮次选择规则。Plan 由传输程序附上官方反馈与前一轮笔记的精确引用和哈希；`memory_basis` 恒为空，防止历史材料直接进入 EoH。

每次外层调用保存提示词哈希、配置模型标识、原始事件记录、响应、输入与输出词元。若出现工具调用、非 JSON 响应、模型身份不可核对、成本缺失或单次调用报告输入超过 30000 词元或输出超过 6000 词元，停止启动新的 solver 评测并记录原因。未知词元不能记为零。先前中止会话的外层费用单列为基础设施成本，不混入新三组的质量对照。

## 故障修复与启动门槛

旧会话保留在原工作区；新运行时与输出位于隔离工作区。旧导出在写出部分算法资产后出现 `PermissionError`，但离线副本未稳定重现。新运行时仅对 Windows 导出资产时的短暂 `PermissionError` 做有限重试，且在最终失败时记录具体资产和错误文本；不改变 solver、目标或选择规则。先编译受影响模块，再用旧原始事实进行无新增模型请求和 solver 调用的完整资产导出、摘要生成、三组同源摘要一致性与成本账本检查。未通过不得开始新共同首轮。

## 判定与报告

首个配对先验证身份、来源、实际消费和预算；流程合格后按原顺序完成其余两个配对，不因成绩好坏换种子。主结果为第 26—100 次预算位置上的最优目标轨迹、曲线面积与固定终点；每配对报告 M−F、F−R 的原始差值及逐实例差异。附加材料是否提出超出现轮反馈的具体可检验问题、Plan 是否使用该问题、实际候选是否符合机制声明，按引用逐轮人工复核。成本按 EoH、外层模型、总词元、请求与耗时分别报告；不作小样本显著性或泛化声明。

完成三对，或出现单独可追溯且具有代表性的机制结果后，才决定是否修改中文学术报告。无论正负均报告；不访问 heldout。若来源、模型、预算、导出或阅读链失败，立即停止新增评测并保留故障事实。
